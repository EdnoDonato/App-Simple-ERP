# Simple ERP

Aplicativo mobile desenvolvido em React Native com Expo.

## Funcionalidades

- Cadastro de produtos
- Controle de estoque
- Registro de vendas
- Registro de compras
- Dashboard financeiro
- Envio de comprovantes via WhatsApp

## Tecnologias

- React Native
- Expo
- AsyncStorage
- React Navigation
- Chat GPT
